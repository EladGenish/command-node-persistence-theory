## Introduction

Command–Node Persistence Theory is an ongoing framework for analysing how objects persist under what bears on them, how maintained structures form, how higher-order objects are sustained by lower maintenance worlds, and what happens when that maintenance becomes hollow, reorganises, fragments, or collapses.

The framework begins from a simple relation: command bears on node, and the node carries that command as shape—either through changes in its own physiology or through structures it builds, finds, or uses. The command does not simply disappear after contact; it remains present in the maintained form. From this relation, CNPT develops accounts of orientation, function, utility, macro–micro maintenance, power, displaced maintenance cost, stability, collapse, and fragmentation.

A central commitment of the project is that terms such as node, command, structure, frame, world, orientation, utility, micro, and macro are not separate kinds of entity. They are aspect-positions of the same object, read from different relations and perspectives.

## Purpose of this repository

This repository is a public working record of the theory as it develops. I will use it to:

- refine the core definitions and formal structure;
- document revisions and conceptual decisions;
- apply the framework to bodies, institutions, identities, theories, education systems, states, and other maintained objects;
- test the framework against difficult cases and competing explanations;
- separate established claims from speculative extensions;
- publish clearer editions, examples, diagrams, and applications over time.

The project should therefore be read as a developing research programme rather than a finished doctrine. Earlier formulations may be revised, compressed, replaced, or rejected as the framework becomes more precise.

## Current direction

The current work focuses on three linked movements:

1. **Encounter and bearing:** how survival-relevant contact becomes command and is carried as physiological or structural shape.
2. **Maintenance and persistence:** how command-shaped forms continue through maintenance, and how function is held across changing conditions.
3. **Macro formation and return:** how similar objects retain and standardise survivable forms, how lower worlds maintain higher macro objects, and how those higher objects return as command topology for the worlds beneath them.

This makes CNPT especially concerned with the difference between visible stability and the maintenance work hidden underneath it.

## Project principles

- Definitions should remain stable enough to be tested.
- Criticism should change the theory when the theory cannot answer it.
- Examples should clarify the mechanism rather than decorate it.
- Similarity to existing frameworks should be stated honestly.
- Unresolved claims should not be presented as settled results.
- The framework must be able to analyse itself as an object and remain open to correction.
